# Cobblemon SHID

**Cobblemon SHID (Simple Hyper-trained IVs Display)** is a mod that displays an IV HUD that shows changes
to hyper-trained IVs whenever a player holds and uses IV candies (or caps) on their Pokémon.

This is a client-side mod.
## Requirements
- Minecraft 1.21.1 Fabric
- Cobblemon 1.6 or newer
- Cobblemon Utility+ (Optional, for their caps)
- Mod Menu (Optional, for the settings screen)

## Settings screen
Open it from Mod Menu.

| Option | Choices | Default |
|---|---|---|
| Show HUD | Yes / No | Yes |
| HUD Style | Full / Compact | Full |
| HUD Position | Locked / Draggable | Locked |
| HUD Size | 0.5x to 3.0x (Based on players' GUI scale) | 1.0x |
| Font Size | 0.5x to 1.5x | 1.0x |
| Background Opacity | 0% (Transparent) to 100% | 90% |

**How to reposition the card:** set HUD Position to Draggable, then drag the card with the mouse while the chat
is open, or hold **Left Alt** (Can be set in Key Binds). Then use 'Locked' to prevent the card from moving around.
